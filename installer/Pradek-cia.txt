ShuffleDrop 0.3 — iPod muzikos tvarkyklė

1. Paleisk ShuffleDrop iš pradžios meniu arba darbalaukio.
2. Prijunk jau paruoštą iPod Shuffle. Bibliotekoje matysi esamas dainas.
3. Dukart spustelėk dainą, kad klausytumeisi per kompiuterį.
4. Skiltyje „Pridėti muziką“ pasirink MP3 ir spausk „Perkelti į iPod“.
5. Pabaigoje saugiai išimk grotuvą per Windows.

Šviesi / tamsi tema perjungiama kairėje apačioje.
Baterijos procento nuskaitymas nepalaikomas.
Tai bandomoji versija. Prieš keisdamas svarbią biblioteką eksportuok dainas į kompiuterį.
Naujai įrašytų dainų grojimas pačiame įrenginyje dar nepatvirtintas.

Programa veikia be iTunes. Reikalinga .NET Framework 4.7.2 arba naujesnė versija.
Windows N leidimams gali reikėti Microsoft Media Feature Pack garso atkūrimui.
Pašalinti galima per Windows nustatymų programų sąrašą.
Pašalinus programą, muzikos atsarginės kopijos kompiuteryje išlieka.
Daugiau informacijos: README.md ir „Pagalba“ programoje.
