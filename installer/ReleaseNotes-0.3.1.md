# ShuffleDrop 0.3.1 — English interface

The app and installer are now in English, making ShuffleDrop easier to share internationally.

## Changes

- Translated navigation, library columns, import controls, playback controls, and theme labels.
- Translated progress messages, errors, removal/recovery confirmations, accessibility labels, and in-app help.
- English installation wizard, shortcuts, and getting-started guide.
- Updated documentation to match the English labels.

## Downloads

- **ShuffleDrop-Setup-0.3.1.exe** — recommended, includes required app libraries.
- **ShuffleDrop-Portable-0.3.1.zip** — extract the entire ZIP and run ShuffleDrop.exe.
- **SHA256SUMS.txt** — download checksums.

Close ShuffleDrop before installing the update. Settings and recovery backups are preserved. Requires Windows with .NET Framework 4.7.2 or later. Windows N editions may need Microsoft's Media Feature Pack for audio preview. The executables are not digitally signed.

This remains an experimental release. Battery percentage and new VoiceOver announcements are unsupported. Playback of newly transferred music on physical hardware has not yet been verified. Keep a separate copy of important music. See the README for the full compatibility limits.
